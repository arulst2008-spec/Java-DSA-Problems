# Java DSA Problems

This repository contains Java DSA solutions organized by topic from the placement-trainer source documents.

## Structure

- `Array-1D/` — 13 problems
- `Array-2D-Matrix/` — 5 problems
- `String/` — 9 unique problems
- `ArrayList/` — 2 problems
- `Linked-List/` — 1 problem
- `Math/` — 3 problems

**Total unique Java problem files: 33**

## Source-document note

The uploaded `String.docx` and `String (1).docx` contain the same 9 String problems, so only one copy is included in the `String/` folder to avoid duplicate source files.

The Java code has been organized into one class per problem. The supplied solution logic has been preserved; class wrappers/imports were adjusted only where needed to make each source file a normal Java source file.

### Review notes

- The source document labels problem 28 as **Find the Index of the First Occurrence in a String**, but its supplied method is named `firstUniqChar`. That method name has intentionally been preserved rather than silently changing the trainer's code.
- The linked-list source refers to `ListNode`; the repository provides a nested `ListNode` definition so the Java file is self-contained.
